Observed defect:
The previous branch called smooth_click(Next) and immediately started mailbox_client.wait_for_code().
Because smooth_click() can return False after swallowing a click failure, the program could remain on the recovery-email page while Graph polling continued for up to 180 seconds.

Changed behavior:
1. Click Next and wait 15 seconds for the verification-code input.
2. If the recovery-email page is still visible, retry with next_button.click(timeout=5000).
3. Wait another 20 seconds for the verification-code input.
4. Start Graph polling only after that input is visible.
5. Report a specific transition error when Next did not take effect.
